# The MD Family: MD5

MD5, designed by Ron Rivest in 1991, produces a 128-bit digest. For years it was everywhere. Today it's a cautionary tale.

## How it's built

MD5 uses the **Merkle–Damgård** construction: the message is padded, split into 512-bit blocks, and each block is mixed into a running internal state through four rounds of bitwise operations. The final state is the digest. Most classic hashes — MD5, SHA-1, SHA-2 — share this skeleton.

## Why it's broken

MD5 is not collision resistant. Researchers can now produce two different inputs with the same MD5 digest quickly on ordinary hardware — this has been used to forge certificates. Its 128-bit size gives only about 64 bits of collision resistance even in theory, and structural weaknesses make it far worse in practice.

> **Do not use MD5 for security.** It's fine as a fast non-adversarial checksum (spotting accidental corruption), but never for signatures, integrity against tampering, or password storage.
